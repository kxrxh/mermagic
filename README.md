# Mermagic

Live Mermaid editor with visual editing, color themes, and SVG/PNG/PDF export.

[![Source editor and live diagram preview](docs/previews/editor.png)](https://kxrxh.github.io/mermagic/)

[![Canvas view with diagram editing tools](docs/previews/canvas.png)](https://kxrxh.github.io/mermagic/)

## Develop

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
bun run preview
```
