# Mermagic

Live Mermaid editor with curated color themes and SVG/PNG export.

Build flowcharts from the preview: add nodes in eight shapes, connect them with
optional labels and four arrow styles, or change the layout direction. Click a
node to edit its label, shape, and color; use **Follow flow** to trace routes.
Every visual edit updates the Mermaid source and can be reversed with **Undo**
or **Redo** in the Source header (or the editor's standard keyboard shortcuts).
For a blank diagram, choose **Start a flowchart** to begin visually.

## Develop

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
bun run preview
```
